# Primeira API Spring Boot

Exercício inicial para praticar a criação de uma aplicação simples com Spring Boot.

## Objetivo

Criar uma API básica com um endpoint de teste.

## Tecnologias

- Java
- Spring Boot
- Maven
- Spring Web

## Como executar

Entre na pasta do exercício:

```bash
cd 01-primeira-api
```

Execute o projeto:

```bash
mvn spring-boot:run
```

Acesse:

```text
http://localhost:8080
```

## Conceitos praticados

- Estrutura básica de um projeto Spring Boot
- Classe principal com `@SpringBootApplication`
- Controller
- Endpoint simples com `@GetMapping`
